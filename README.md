# Monaco XML Editor

Офлайн-редактор Monaco ECU Exchange XML для Windows 10/11 x64.

## Готовая программа

Откройте **Actions → Build Windows EXE → последний успешный запуск → Artifacts → Monaco_XML_Editor-Windows-x64**. Распакуйте ZIP и запустите `Monaco_XML_Editor.exe`. Python, установка программы и отдельная Windows для сборки не нужны. Артефакт хранится 90 дней; новую сборку можно запустить кнопкой **Run workflow**.

## Использование

1. Нажмите «Открыть XML».
2. Раскройте ECU / группу. Дважды нажмите параметр или выделите его и нажмите Enter.
3. Измените Value или DisplayValue и нажмите «Применить». По умолчанию изменение Value копируется в DisplayValue; флажок отключает это поведение.
4. Нажмите «Сохранить как…». По умолчанию предлагается отдельный файл `_edited.xml`.

Сортировка меняет только отображение; порядок узлов XML сохраняется. Отсутствующие поля не создаются. Неоднозначные записи пропускаются и учитываются в статусе. Поддерживаются пространства имён и кодировки из XML, включая UTF-16. Экспорт — UTF-8; сериализация может изменить оформление XML (кавычки, запись пустых элементов). Комментарии и остальные узлы сохраняются. DTD и внешние сущности не поддерживаются.

Жёлтый цвет отмечает изменённые строки. «Отменить изменения» возвращает состояние при открытии или последнем сохранении. XML обрабатывается только локально, без отправки на сервер. GitHub получает исходники программы, а не ваши XML.

## Сборка

Workflow `.github/workflows/build-windows.yml` запускается при push в main и вручную. На Windows устанавливаются Python 3.12 x64 и зависимости из `requirements-build.txt`, выполняются XML-тесты, затем PyInstaller создаёт один EXE без консоли. После сборки проверяется запуск интерфейса Tk; в ZIP добавляется SHA256.

На Windows для локальной сборки:

```powershell
python -m pip install -r requirements-build.txt
python -m unittest discover -s tests -v
python -m PyInstaller --noconfirm --clean --onefile --windowed --noupx --name Monaco_XML_Editor Monaco_XML_Editor.pyw
```

Основа поведения — предоставленный пользователем HTML-редактор. Для проверки на реальных данных нужен образец Monaco XML; автоматические тесты используют синтетические документы. Программа не проверяет допустимость значений для конкретного ECU.
